# Security and world-data safety

ForceBlend is a proof of concept that intentionally rewrites Minecraft region files. Always keep an offline backup and
verify that it can be restored before using the mod on a world you care about.

## Supported release

Version 1.0.0 is the current release. Only Minecraft 1.18.2 and 26.2 have been verified in game. Other versions inside
the declared metadata range are compatibility targets, not guaranteed or actively supported environments.

There is no guaranteed maintenance schedule, response time, or future update. The community may fork the project and
publish fixes under the MIT License.

## Reporting a vulnerability

Please use GitHub's private security advisory feature for an exploit, malicious world, or issue that could cause data
loss. Do not post sensitive saves, credentials, or private paths in a public issue.

Useful reports include the ForceBlend, Minecraft, Fabric Loader, Java, and operating-system versions; a minimal
reproduction; the possible impact; and sanitized logs. A report may not receive a quick response, so keep your backup
and do not continue testing on the original world.
